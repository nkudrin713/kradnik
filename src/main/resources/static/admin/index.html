Пояснения

Треки: активные / ожидающие. На графике нагрузки синий — очередь, зелёный — работа.

Графики памяти: зелёный — занято, пунктир — максимум или лимит. Контейнер включает процессы и файловый кэш.

GC показывает суммарное время сборки, а не паузы бота. Дополнительные ошибки могут совпадать с неуспешными задачами.
